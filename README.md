# Two Abreast — the view from behind

An interactive 3D simulation showing why a group of cyclists riding a maximum of
**two abreast** can *look* three or four wide when viewed from a car behind:
perspective compresses depth, so staggered pairs visually overlap into a wider
wall of riders.

**▶️ Live demo: https://jamesecc.github.io/two-abreast/**

No login, no install — it runs entirely in the browser.

## About

- Single self-contained `index.html` — no dependencies, no build step.
- Drag/slider controls to sweep the camera from overhead down to the driver's
  eye, adjust group size, formation chaos, following distance, and more.
- The riders genuinely never exceed two abreast; the "looks like N abreast"
  readout is measured from the group's actual width, not faked.

## Running locally

Just open `index.html` in any modern browser.
